# Console v0.3 — Rust build hotfix 2026-10-21

The first Ubuntu mini-PC Docker build from v0.3 reported `error[E0505]` in `services/api/src/state.rs:305`: `event.robot_id` was borrowed while `event` was moved into `serde_json::to_value(event)`. The fix is to serialize by reference with `serde_json::to_value(&event)`. Two unrelated Rust warnings (unused `Path`, unnecessary `mut entry`) were also cleaned up.

The user-provided build log indicates the Next.js web image was built. The Rust API build failed, so Docker Compose did not complete and `docker compose logs` can be empty when no containers were created.

**Verification status:** Node/Python static tests pass on the patched source; the post-patch Rust/Docker rebuild still needs to run on Ubuntu. Do not claim it passes until `sudo docker compose up --build -d` and `python3 scripts/doctor.py` succeed.
